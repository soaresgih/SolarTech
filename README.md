# SolarTech

Plataforma inteligente de simulação de viabilidade para energia solar residencial.

## Funcionalidades

- Simulação anual da conta de energia
- Estimativa de economia
- Quantidade de placas solares
- Área necessária
- Cálculo de payback
- Marketplace de equipamentos solares

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Projeto acadêmico desenvolvido para a disciplina de UPX com foco em sustentabilidade, acessibilidade e análise de viabilidade da energia solar residencial.
